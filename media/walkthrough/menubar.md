# BuildPilot Bar: your menu bar

A small compass icon at the top right of your Mac's screen:

- **The icon** shows how many Claude Code sessions are working. It switches to a **!** with a number when sessions need you.
- **Click it** to see every session in every project, what each one is doing, which one is waiting for your approval, and your 5-hour and weekly plan limits.
- **Click a session** to jump to it in BuildPilot.
- **A notification** arrives when a session starts waiting for you, even when VS Code is closed.

It only reads BuildPilot's local data and never sends anything. Remove it anytime: **Connect → Menu bar → Remove**.
