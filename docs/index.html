What you get

Everything you wish Claude Code told you

Who needs you, right now

Every Claude build across your projects. The one waiting for approval comes first, with the exact command and a button that jumps to its terminal tab.

Live, plain-English status

"Running npm test · 4 min", "Editing pricing.tsx", "may be stuck". Errors appear as they happen, with one click to copy them for Claude.

Never hit a limit by surprise

Your 5-hour and weekly use, when each resets, and when you'll run out at your pace. A heads-up at 80%, before it's too late.

Where your tokens go

See what's eating each chat: the starting load from tools and MCP, giant file reads, subagents. Get tips that actually cut usage.

Safe parallel builds

Start another Claude in its own copy of the project. Review each change and merge. On a conflict, nothing breaks and you get a fix prompt.

Who changed this file?

See which build touched a file and when, with one-click undo (a safety save point comes first). Codex sessions show up too.
